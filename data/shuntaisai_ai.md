# 駿大祭 AI（ShuntaisaiActionSelector）検討メモ

## 評価条件

* キャラ: [初うらら♪さくさくら]ハルウララ（5/5）、因子スピード3×6
* サポカ（全て完凸、スキル無し）: ミスターシービー、エフフォーリア、メイショウドトウ、マヤノトップガン、フォーエバーヤング、吾妻(SSR)
  * スピ2/スタ/パワ/賢さ/友人 → タイプ5種で演目稽古の5種効果あり
  * 演目担当: スピ2（シービー、エフフォーリア）、スタ（ドトウ）、パワ（マヤノ、リンク）、賢さ（フォーエバーヤング）、根性は編成サポカ無し（ゲストのみ）
* 評価: `Runner.shuntaisaiSetting` のスコア上位20%の平均
  * スピ×2.0（上限3200）、スタ×1.5（2500）、パワ×1.0（2400）、根性×0.5（2200）、賢さ×1.0（2600）、SP×3.0（12000）
  * 評価上はステータスの上限が無く、SPの重みが最大 → スピードは3200で頭打ちにしてSP・スタミナに回すのが理想
* 実行方法: `./gradlew :jvm:run --args="eval 回数 [Option配列JSON...]"`（`debugShuntaisai.kt`）
  * 100000回で約40秒（16スレッド）、20000回で概ね±30〜50程度のブレ
  * `./gradlew :jvm:run --args="dump"` でデフォルト設定をJSON出力（パラメータ探索用）

## まとめ（最終結果）

* 最終評価（デフォルト設定、100000回×2）: **43690 / 43688**（全体平均42139）、仮実装は30316（20000回）
  * 上位20%の平均ステータス: 4668/2279/2511/1266/1871/SP9681、大成功率 0.955/0.996/1.000
* 効果が大きかった変更（概算）
  1. 独自の評価関数（体力の上限考慮、評価単位の重み、大成功に足りない演目Lvの優先）: +9300
  2. 教えの割り当て探索（シニアのスピ協力・スタ特化、クラシックのスピ特化など）: +1600
  3. 演目ゲージの評価を大きくする（10→54、シニア75）、演目Lv加点は小さく: +1000
  4. 根性の演目稽古を止める（クラシック・シニア）: +480（パラメータ調整後は+50程度）
  5. 目標外レースに出ない: +440
  6. 転成の組み合わせ、Lv上限の演目のゲージ評価: 各+80前後
* 効果が無かった/逆効果だった仮説: ステータス上限マージン、演目ごとのゲージ倍率、合宿前後の体力評価、駿大祭後のレース解禁、演目稽古の早期実行（サポカ固定解除）、友人お出かけの積極使用、ファイナルズ直前のゲージ減衰、第1回発表会の大成功を優先
* 今後の課題
  * 教え割り当て・パラメータはこの編成用。他の編成（根性サポカ入り等）では holdPractice や教えの再探索が必要
  * 友人お出かけの結果候補にイベント効果が含まれない（シミュレータ側）ため、お休み時の置き換えでのみ使用している

## 仮説

1. 体力の重みが高すぎてお休みが多い → hp/hpKeepを下げてトレーニング回数を増やす
2. 評価の重み・上限に合わせてステータス重みを設定する（SP重視、スピード上限到達後はスピード重みを下げる）
3. 進捗発表会の大成功が重要（第2回: 全トレLv+1、演目担当+5人、駿大祭ボーナス強化） → 次の発表会の目標Lvに足りない演目のゲージ・演目稽古を優先する
4. 演目稽古は演目Lvが上がり、教え・稽古効果が上がるので価値を上乗せする
5. 教えの割り当てはメモ（shuntaisai_memo.md「教え選択（暫定）」）のスピ2スタパワ賢さ吾妻のパターンをベースにする
6. 吾妻のお出かけ（最低演目Lv+1、体力回復）を体力が減った時に使う

## 検討ログ

### #0 → #1
* 仮実装はお休みの体力回復を最大体力超過分も評価していたため、体力満タンでもお休みしていた
* BaseActionSelector3のInt重みを使わず、全行動を独自に評価（評価値=Runner.shuntaisaiSettingと同じ単位）
  * ステータスは評価上限-statusCapMarginまで、体力は最大体力までを評価
  * 次の発表会の大成功に足りない演目（以降の合宿終了ボーナス考慮）のゲージ・演目稽古・吾妻お出かけにlevelUrgency加算
* 大成功率はほぼ100%に。上位20%の内訳はSPが約2/3（SP×3.0が支配的）

### 根性の演目稽古を止める（メモの攻略より）

  * 根性の演目Lvは合宿終了と吾妻お出かけ（最も低い演目Lv+1）で上がるので、大成功条件は概ね満たせる
* holdPractice/holdPracticePenaltyを追加（大成功にLvが足りない場合は除外）（20000回、基準41760）
  * 根性を全期間止める: 42238（+480）、ペナルティ1000でも42231

  * 根性をクラシック・シニアのみ: 42289、ジュニア・クラシックのみ: 41845 → シニアで止めるのが重要、ジュニアは不要
